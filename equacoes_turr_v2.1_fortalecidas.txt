1. EQUAÇÃO MESTRA GPE-CAPUTO (versão final corrigida)
═══════════════════════════════════════════════════════════════════════════════════════

                         ℏ²           
iℏ ∂Ψ/∂t = - ──── ∇²Ψ + g|Ψ|²Ψ + αN(r,t)|Ψ|²Ψ + γℏt₀^{β-1} D^β_t[Ψ]
                        2m           

onde:
• ℏ = 1.054571817×10⁻³⁴ J·s (constante de Planck reduzida)
• m = massa efetiva do modo coletivo
• g = força de interação não-linear [J·m² em 2D]
• α = coeficiente de acoplamento narrativo (adimensional)
• N(r,t) = campo narrativo externo (adimensional)
• γ = fator de escala Caputo (adimensional, tipicamente 0.1)
• t₀ = escala temporal de referência (tipicamente 1s)
• β ∈ [0.3, 0.9] = ordem fracionária (memória)

Derivada de Caputo:
                    1           ᵗ   Ψ'(s)
D^β_t[Ψ] = ─────────── ∫  ────────── ds
           Γ(1-β)      ₀  (t-s)^β

VERIFICAÇÃO DIMENSIONAL:
• Todos os termos têm dimensão [ML²T⁻²]·[Ψ] ✓
• [g] = [ML⁴T⁻²] (energia × área) ✓
• [γℏt₀^{β-1}D^β] = [J·s]·[s^{β-1}]·[s^{-β}] = [J] ✓

2. HOLONOMIA TRIANGULAR R_Δ (versão geométrica)
═══════════════════════════════════════════════════════════════════════════════════════

Para ciclo triangular (i → j → k → i) com atrasos τᵢⱼ, τⱼₖ, τₖᵢ:

Déficit de fase total:
        Δφ_cycle = -ω × (τᵢⱼ + τⱼₖ + τₖᵢ)

Holonomia local:
        R_Δ(i,j,k) = cos(Δφ_cycle)

Holonomia global (média sobre N_△ triângulos):
                    1      
        R_Δ^global = ──── Σ  R_Δ(i,j,k)
                    N_△  △

Holonomia normalizada:
        R_Δ^norm = (R_Δ + 1) / 2  ∈ [0, 1]

LIMIARES REFINADOS:
        TRAVADO:        R_Δ ≥ 0.90, |μ| ≤ 10°, σ ≤ 15°
        QUASE_TRAVADO:  R_Δ ∈ [0.80, 0.90)
        MARGINAL:       R_Δ ∈ [0.65, 0.80)
        PARCIAL:        R_Δ ∈ [0.50, 0.65)
        FRACO:          R_Δ ∈ [0.35, 0.50)
        DESORDENADO:    R_Δ < 0.35

3. PLV (Phase Locking Value) COM CORREÇÃO DE ATRASO
═══════════════════════════════════════════════════════════════════════════════════════

        PLV_ij = |⟨ exp(i[φᵢ(t) - φⱼ(t - τᵢⱼ) - ωτᵢⱼ]) ⟩_t|

onde:
• φᵢ(t) = fase instantânea do sinal i (via transformada de Hilbert)
• τᵢⱼ = atraso físico entre i e j
• ω = frequência angular dominante
• ⟨·⟩_t = média temporal sobre janela deslizante

INTERPRETAÇÃO:
        PLV = 1.0: sincronização perfeita
