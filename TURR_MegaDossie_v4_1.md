## 4.9 Crosswalk — variáveis, métricas, equivalências

### 4.9.1 Forma unificada (esqueleto mínimo)

A maior parte dos documentos converge (com variações) para um **sistema acoplado**:

1) **Campo físico (ψ / Ψ)** — superfluido/éter/realidade responsiva:
\[
i\hbar \,\partial_t \psi =
\left(
-\frac{\hbar^2}{2m}\nabla^2
+ V(\mathbf{x},t)
+ g(\mathbf{x},t)\,|\psi|^2
+ \mathcal{M}_\alpha[\psi]
\right)\psi
\]

2) **Campo narrativo (N)** — driver semântico/intentionalidade coletiva:
\[
\partial_t N
=
D_N \nabla^2 N
- \gamma_N N
+ S(\mathbf{x},t)
+ \int K(\mathbf{x}-\mathbf{x}',t-t')\,N(\mathbf{x}',t')\,d\mathbf{x}'dt'
\]

3) **Acoplamento “narrativo”** — aparece como:
- modulação da rigidez: \(g \leftarrow g_0(1+\beta N)\)
- ou potencial adicional: \(V \leftarrow V_0 + \beta N\)

4) **Métrica holonômica (E‑R‑C / RΔ)** — triângulos de fase com atrasos:
\[
R_\Delta = \left|\left\langle e^{i\Phi_{ABC}(t)}\right\rangle_T\right|
\quad,\quad
\Phi_{ABC}(t)=
\sum_{(i\to j)\in\triangle}\left[\phi_i(t-\tau_{ij})-\phi_j(t)+\omega\tau_{ij}\right]
\]

### 4.9.2 Tabela de correspondência de símbolos

| Símbolo | Significado operacional | Onde aparece |
|---|---|---|
| ψ / Ψ | campo físico (éter/superfluido/realidade) — GPE/NLSE | TURR, Estator, ERC, Bob |
| Φ | campo relativístico (NKG/φ⁴) em algumas versões | Bob/CT |
| N(x,t) | campo narrativo / densidade de intencionalidade / semântica | Estator, TURR, Bob, CT-v5 |
| α | ordem fracionária/Caputo ou parâmetro de modulação (depende do doc) | Estator, TURR |
| β | força de acoplamento narrativo / parâmetro de coerência | TURR, Estator, CT-v5 |
| RΔ / R_Δ | holonomia triangular / coerência topológica | TURR, Estator, Bob, ERC |
| PLV | phase-locking value (par-a-par) | CT-v5, TURR/Estator |

| DACM/NSM | operador de modulação cíclica aplicado a sinais (ponte para ψ ou N) | DACM docs + conexão TURR |
